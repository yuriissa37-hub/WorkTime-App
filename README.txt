WorkTime Web – PWA
==================
This is a lightweight static PWA. No npm, Node.js, API key, or build step is required.
Upload the CONTENTS of this folder to a static HTTPS host (not the ZIP itself unless the host supports ZIP deployment).
Open the HTTPS URL on Android Chrome/Samsung Internet and choose Install app / Add to Home screen.
Data is stored locally in the browser on this device. Use Export data regularly to back up records.
